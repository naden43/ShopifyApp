# SAWAQNY 🛍️

SAWAQNY is a native iOS M-Commerce application developed as a graduation project during the Information Technology Institute (ITI) 9-Month Program (Intake 44).

The application provides a seamless shopping experience that allows users to browse products, search for items, manage their shopping cart and wishlist, place orders, and track their purchases directly from their mobile devices.

## 📱 Features

### Authentication

* User Registration and Login
* Guest Mode for browsing without an account
* Firebase Authentication integration

### Product Browsing

* Browse products from popular brands such as Adidas, Nike, and more
* View products by brand
* Explore detailed product information including:

  * Multiple product images
  * Available sizes
  * Available colors
  * Customer reviews

### Search & Filtering

* Search across all products
* Search within specific categories and subcategories
* Filter products by price
* Filter by main categories:

  * Men
  * Women
  * Kids
  * Sale
* Filter by subcategories:

  * Shoes
  * T-Shirts
  * Accessories
  * And more

### Wishlist & Cart

* Add products to wishlist
* Remove products from wishlist
* Add products to shopping cart
* Remove products from shopping cart

### Order Management

* Place orders with selected delivery addresses
* Add and edit multiple addresses
* Online payment support
* Cash on Delivery (COD) support
* View current and previous orders
* Track order history

### Currency Support

* Switch between:

  * Egyptian Pound (EGP)
  * US Dollar (USD)

### User Experience

* Clean and intuitive user interface
* Responsive and user-friendly navigation
